## 生成ワークフロー（推奨手順）

### STEP 1：背景のみのシーンから始める（難易度★）
```
カット7（農村全景）→ カット10（麦畑・後ろ姿）→ カット19（高度成長期の街）
```
→ この3シーンで画風・色調・雰囲気を確定させる

### STEP 2：人物1〜2人のシーンへ（難易度★★）
```
カット8（台所・母と子）→ カット14（父と息子・夕暮れ）→ カット9（防空頭巾）
→ カット11（小学校）→ カット12（川遊び）→ カット17（工場）
```

### STEP 3：複数人物・複雑なシーン（難易度★★★）
```
カット13（集会所・テレビ）→ カット21（夏祭り・出会い）
```
→ 各シーン3〜5枚生成して最良を選ぶ

## ツール別設定まとめ

| ツール | 推奨設定 | スタイル指定 |
|---|---|---|
| **Midjourney v6** | `--ar 16:9 --style raw --no chibi,moe` | ベーススタイルプロンプト末尾に追加 |
| **DALL-E 3** | GPT-4oから指示 | 「mature anime film style, Showa Japan, NOT moe」を先頭に |
| **Adobe Firefly** | 英語プロンプト | Content type: Art / Style: Anime |
| **Stable Diffusion** | AnimagineXL等のLoRA使用 | `showa, sfw, sepia, anime film` タグ |
| **Niji Journey** | `--niji 6 --style scenic` | 日本語プロンプト対応 |

## キャラクター一貫性を保つコツ

1. **最初に誠一の顔設定を1枚生成**して固定する（seed値をメモ）
2. Midjourneyの場合は `--seed XXXXX` で同じ顔を維持
3. DALL-E 3の場合は生成された画像の描写を次のプロンプトに文章で組み込む
4. 各シーンで**誠一は後ろ姿・横顔・遠景**にすると一貫性の問題が減る
5. 幼少期・少年期は**顔より情景描写**を重視（感情は風景で語る）
