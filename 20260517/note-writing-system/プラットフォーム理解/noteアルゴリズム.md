# noteアルゴリズム（公開情報ベースの運用指針）

※公式の完全な仕様は非公開のため、観測・ベストプラクティスとして運用する。

## 記事が届きやすくなる要因（推測・実践）

| 要因 | 具体策 |
|------|--------|
| 初動エンゲージメント | 公開後24〜48時間のスキ・コメント・読了 |
| 読了率 | リード文・見出しで最後まで読ませる |
| 更新・継続 | 定期的な投稿でアカウント信頼性を上げる |
| フォロワーとの関係 | コメント返信・マガジン・シリーズ化 |
| 外部流入 | X・ブログからのリンク（初動を作る） |

## タイムライン・おすすめに乗りやすい投稿設計

1. **公開タイミング**：フォロワーが活発な時間帯（平日夜・休日朝など、自分の分析で決める）
2. **初動の作り方**：公開直後にXで1投稿、コメントを促す締め文
3. **マガジン登録**：シリーズはマガジンにまとめて回遊を促す

## 伸びにくいパターン

- タイトルと中身の不一致（離脱・低評価）
- 極端に短い or 冗長すぎる記事
- 画像・見出しなしの長文塊
- スパム的な大量投稿

## 運用KPI（自分用）

| 指標 | 目安 | 計測 |
|------|------|------|
| スキ率 | 閲覧数に対するスキ | note分析 |
| コメント数 | 1記事あたり | 手動 |
| フォロー転換 | 記事からのフォロー増 | 週次 |
| 読了（推定） | 滞在・スクロールは定性で | コメント内容 |

## 執筆時の問い

> 「公開後24時間以内に、誰が・なぜスキ・コメントしたくなるか？」

答えが弱い場合、リード文か締めのCTAを見直す。
