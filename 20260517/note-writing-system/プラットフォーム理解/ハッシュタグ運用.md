# ハッシュタグ運用

noteの発見性・関連記事表示に使う。過不足なく、一貫性を持たせる。

## 基本ルール

| 項目 | 推奨 |
|------|------|
| 個数 | 3〜7個 |
| 構成 | 大カテゴリ1 + 中テーマ2〜3 + 記事固有1〜2 |
| 統一 | アカウントでよく使うタグを固定する |

## タグの種類

### 1. ブランドタグ（毎回 or よく使う）

```
#あなたのハンドル名
#シリーズ名
```

### 2. ジャンルタグ

```
#副業
#note運営
#ライティング
```

### 3. 記事固有タグ

```
#初心者向け
#週5時間副業
```

## 選び方チェックリスト

- [ ] タグをクリックしたとき、関連記事が自分のテーマと合っているか
- [ ] 人気すぎるタグだけに頼っていないか（埋もれる）
- [ ] ニッチすぎて誰も検索しないタグになっていないか
- [ ] タイトル・本文と無関係なタグを付けていないか

## 配置場所

- 記事末尾（締めの後）
- または note のタグ入力欄に同じものを設定

**例**

```
#副業 #会社員副業 #note初心者 #週5時間 #副業ロードマップ
```

## タグ一覧管理（自分用）

| タグ | 用途 | 使用頻度 |
|------|------|----------|
| | | 毎回 / たまに |

## 避けること

- 10個以上のタグ（スパム扱いの印象）
- 無関係なトレンドタグの付け足し
- 毎回まったく違うタグだけ（ブランドが伝わらない）
