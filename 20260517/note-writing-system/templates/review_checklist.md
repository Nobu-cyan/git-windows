# 投稿前チェックリスト

執筆完了後、公開前にすべてにチェックを入れる。

## 戦略・ターゲット

- [ ] ターゲット読者が1人に絞られている
- [ ] ペインポイントに応える内容になっている
- [ ] タイトルの約束が本文で果たされている

## タイトル

- [ ] ベネフィットが1文で伝わる
- [ ] 32文字前後でスマホ表示を確認した
- [ ] 煽り・誇大表現になっていない
- [ ] 本文と内容が一致している

## リード文

- [ ] 最初の3行で「自分ごと」になっている
- [ ] 3行目で記事の約束が明示されている
- [ ] 次の見出しに自然につながる

## 見出し・構成

- [ ] H2が3〜5個ある
- [ ] 各H2にH3が2〜3個ある
- [ ] H2だけ読んでも流れがわかる
- [ ] 導入→本論→結論の順になっている

## 本文品質

- [ ] 文字数が3,000〜5,000字の範囲内
- [ ] 各H2に具体例・数字・体験談のいずれかがある
- [ ] 1段落が長すぎない（スマホで読みやすい）
- [ ] 専門用語に説明がある
- [ ] 誤字脱字・変換ミスを確認した

## 締め・CTA

- [ ] 要点の要約がある
- [ ] 次のアクションが1つに絞られている
- [ ] スキ・コメント・フォローのいずれかを促している

## プラットフォーム

- [ ] ハッシュタグ3〜7個、内容と関連している
- [ ] 内部リンク（関連記事）を必要に応じて入れた
- [ ] サムネイルを設定した（または意図的にデフォルト）
- [ ] 抜粋・説明文を書いた

## 最終確認

- [ ] 自分が初めて読む人の視点で通読した
- [ ] 公開後24時間の初動施策（X投稿など）を決めた
- [ ] `outputs/` に最終版を保存した

---

**判定**

- すべてチェック → 公開OK
- 1つでも未チェック → 該当セクションを修正してから公開
