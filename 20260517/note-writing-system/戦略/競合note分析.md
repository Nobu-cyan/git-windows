# 競合note分析

同ジャンルの人気記事を分析し、差別化ポイントを見つける。

## 分析対象の選び方

- 同ジャンルで「スキ数1,000以上」の記事を3〜5本
- フォロワー数が近いクリエイターの記事
- 直近3ヶ月以内に投稿された記事

## 差別化の4つの軸

1. **深さ**：同テーマをより詳しく・実践的に
2. **視点**：初心者目線 / プロ目線 / 失敗談目線
3. **形式**：チェックリスト / ストーリー / データ分析
4. **ターゲット**：より狭い層に特化

## 真似してよいこと / 避けること

### 真似してよい

- 見出しの論理構成
- リード文のフックの型
- 記事の長さ・密度

### 避ける

- タイトルの丸パクリ
- 文体・キャラクターのコピー
- 体験談の捏造
