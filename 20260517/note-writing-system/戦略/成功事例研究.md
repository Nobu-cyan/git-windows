# 成功事例研究

バズった記事・伸びた記事から再現可能なパターンを抽出する。

## 成功記事の共通パターン

### タイトル

- 数字が入っている（「3つの方法」「90日で」）
- ベネフィットが明確（読者の得が一瞬でわかる）
- 好奇心ギャップ（「知らないと損する」「実は」）

### リード文

- 1行目で共感 or 衝撃
- 3行以内で「続きを読みたい」状態を作る
- 結論を少し先出しして期待値を上げる

### 本文

- H2ごとに1つのメッセージ
- 具体例・数字・体験談が各セクションにある
- 箇条書き・表で視認性を確保

### 締め

- 要約（3行以内）
- 次のアクションが1つに絞られている
- フォロー・スキ・コメントのいずれかを促す

## 再現テンプレ（成功パターンの抽象化）

```
【フック型】〇〇な人、実は△△していませんか？
【数字型】〇〇を△日で達成した3ステップ
【ストーリー型】失敗→気づき→変化の実話
【リスト型】〇〇する前に確認すべき5つのこと
```
