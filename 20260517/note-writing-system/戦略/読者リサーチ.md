## 基本プロフィール

| 項目 | 内容 |
|------|------|
| 年齢層 | 例：25〜35歳 |
| 職業・立場 | 例：会社員・副業挑戦中 |
| 経験レベル | 初心者 / 中級者 / 上級者 |
| 利用シーン | 例：通勤中・寝る前にスマホで読む |

## リサーチ方法チェックリスト

- [ ] note内の関連記事のコメント欄を読む
- [ ] X（Twitter）で悩み系キーワードを検索
- [ ] 競合クリエイターのフォロワー層を観察
- [ ] 自分の過去記事の反応が良かった層を振り返る
