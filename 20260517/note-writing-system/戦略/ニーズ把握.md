# ニーズ把握

読者の「痛み」と「理想の未来」を対比させ、記事の軸を決める。

## ペインポイント分析フレーム

### 1. 現状の痛み（Before）

| カテゴリ | 具体的な悩み |
|----------|--------------|
| 時間 | |
| お金 | |
| スキル | |
| 感情 | |
| 人間関係 | |

### 2. 理想の状態（After）

| カテゴリ | 読者が望むゴール |
|----------|------------------|
| 時間 | |
| お金 | |
| スキル | |
| 感情 | |
| 人間関係 | |

### 3. 障壁（なぜ今できないのか）

- 情報不足
- 方法がわからない
- 自信がない
- 時間がない
- お金がない
- 過去に失敗した経験

## ニーズの深さレベル

| レベル | 内容 | 記事例 |
|--------|------|--------|
| Lv1 | 情報欲 | 「〇〇とは何か」 |
| Lv2 | 方法欲 | 「〇〇のやり方」 |
| Lv3 | 結果欲 | 「〇〇で月5万稼いだ話」 |
| Lv4 | 共感欲 | 「失敗から這い上がった話」 |

**推奨**：Lv2〜Lv3が最もエンゲージメントが高い。

## 記事テーマ決定シート

```
テーマ：
ペインポイント（1文）：
提供する解決策（1文）：
読者が得られるベネフィット（1文）：
```
