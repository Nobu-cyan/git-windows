# ポジショニング

「誰に・何を・なぜ自分から」提供するかを定義する。

## ポジショニングステートメント

```
[ターゲット] に対して、
[独自の価値] を提供する。
競合との違いは [差別化要素] である。
```

### 記入例

```
副業初心者の会社員に対して、
「週5時間で始める」現実的な副業設計を提供する。
競合との違いは、フルタイム副業ではなく本業と両立する視点である。
```

## 3つの柱（コンテンツ軸）

| 柱 | テーマ | 読者への約束 |
|----|--------|--------------|
| 柱1 | | |
| 柱2 | | |
| 柱3 | | |

## ブランドボイス

| 項目 | 設定 |
|------|------|
| トーン | 例：親しみやすい / 論理的 / 熱血 |
| 一人称 | 例：僕 / 私 / 自分 |
| 避ける表現 | 例：上から目線、専門用語の乱用 |
| 使う表現 | 例：「正直に言うと」「実際にやってみた」 |

## ポジショニングマップ（簡易）

```
        専門性 高
            ↑
    [競合A]  |  [あなた]
            |
    [競合B]  |  [競合C]
            →
        親しみやすさ 高
```

自分が「専門性×親しみやすさ」のどこに立つかを意識する。

- [ ] 他の記事とトーンが一貫しているか
