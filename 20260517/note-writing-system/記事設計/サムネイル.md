# サムネイル

noteの一覧・SNSシェアで第一印象を決める要素。

## 基本スペック

| 項目 | 推奨 |
|------|------|
| 比率 | 16:9 または 1.91:1（note推奨に合わせる） |
| 文字数 | サムネ上の文字は10〜15字以内 |
| 色 | ブランドカラー2色 + 白 or 黒のテキスト |
| スタイル | 記事シリーズで統一感を出す |

## サムネに入れる要素

1. **メインコピー**：タイトルの要約（ベネフィット or 数字）
2. **サブコピー**（任意）：ターゲット or 期間
3. **視覚的アイコン**：テーマが一目でわかるイラスト・写真

## 型

### 型A：数字強調

```
[大きな数字]
[短いラベル]
例：「3ステップ」「週5時間」
```

### 型B：Before/After

```
[Before] → [After]
例：「0円 → 月3万」
```

### 型C：問いかけ

```
[疑問文を大きく]
例：「何から始める？」
```

## チェックリスト

- [ ] スマホのサムネイルサイズで文字が読めるか
- [ ] タイトルとメッセージが一致しているか
- [ ] 他記事と並んだときに埋もれないか（コントラスト）
- [ ] 煽り・誤解を招く表現になっていないか

## ツール例

- Canva（テンプレート豊富）
- Figma（シリーズ統一に向く）
- note公式のOGP（未設定時は自動生成されるため、意図した画像を設定推奨）
