# 内部リンク

関連記事への導線で、読了時間・フォロー率・回遊を高める。

## 内部リンクを入れるタイミング

| 位置 | 目的 |
|------|------|
| 本論の途中 | 深掘りしたい読者向けの関連記事 |
| まとめの直前 | シリーズの次の記事へ誘導 |
| 記事末尾 | おすすめ記事3本のリスト |

## リンクの書き方

```markdown
※〇〇について詳しくは、[関連記事のタイトル](記事URL)で解説しています。
```

```markdown
---
**あわせて読みたい**
- [記事タイトル1](URL)
- [記事タイトル2](URL)
- [記事タイトル3](URL)
```

## 選定基準

1. **テーマの連続性**：前編→後編、基礎→応用
2. **読者の次の疑問**：この記事を読んだ人が次に知りたいこと
3. **反応の良い記事**：スキ・コメントが多い過去記事を優先

## 避けること

- 無関係な記事へのリンク（クリック率が下がる）
- 1記事に5本以上のリンク（散らかる）
- リンクだけで本文の価値を代替する

## シリーズ設計シート

| 順番 | 記事タイトル | 役割 | リンク先 |
|------|--------------|------|----------|
| 1 | | 入門・問題提起 | → 2 |
| 2 | | 方法・実践 | → 3 |
| 3 | | 応用・事例 | → 1（循環） |
