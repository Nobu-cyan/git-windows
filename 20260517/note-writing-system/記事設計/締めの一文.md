# 締めの一文

記事の最後で、読者の「次の一歩」とエンゲージメントを設計する。

## CTAの種類（1記事に1つに絞る）

| 種類 | 例文 | 目的 |
|------|------|------|
| 行動 | 今日、〇〇を1つだけやってみてください。 | 実践促進 |
| スキ | 役に立ったらスキを押してもらえると嬉しいです。 | スキ数増加 |
| フォロー | 続きはフォローでお届けします。 | フォロワー獲得 |
| コメント | あなたの〇〇は何ですか？コメントで教えてください。 | コメント誘発 |
| シェア | 同じ悩みの人にシェアしてもらえると助かります。 | 拡散 |

## 締めの構成テンプレ

```markdown
## まとめ

[要点を3行以内]

---

[CTA：次のアクションを1つ]

[任意：フォロー・関連記事・プロフィールへの一言]
```

## 締め文の例

### 行動型

```
まずは今日、〇〇を15分だけ試してみてください。
完璧でなくていい。一歩踏み出した人から、景色が変わります。
```

### 共感 + スキ型

```
ここまで読んでくださったあなたは、もう一歩前に進んでいます。
気に入ったらスキで応援してもらえると、次の記事を書く励みになります。
```

### コメント型

```
あなたが今一番困っていることは何ですか？
コメントで教えてもらえれば、次の記事のテーマにします。
```

## 避ける締め

- 長すぎる総括（本文で書いたことを繰り返すだけ）
- CTAが複数（スキ・フォロー・コメント・購入を全部頼む）
- 押し付けがましい販売文（有料記事以外では控えめに）

## チェックリスト

- [ ] 要点の要約がある
- [ ] 次のアクションが1つに絞られている
- [ ] タイトル・リード文の約束を果たしている
- [ ] 読後に「やってみよう」と思える一文がある
