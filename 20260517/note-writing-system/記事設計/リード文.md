# リード文テンプレ（最初の3行）

**目的**：最初の3行で「これ自分のことだ」と思わせ、続きを読ませる。

## テンプレA：共感フック

```
[読者の悩みをそのまま言葉にする]。
[共感の一言：わかります / 僕もそうでした]。
この記事では、[具体的なベネフィット]をお伝えします。
```

**例**
```
「何から始めればいいかわからない」——副業を考えていると、ほとんどの人がそう感じます。
僕も最初の3ヶ月は、情報を集めるだけで一歩も進めませんでした。
この記事では、週5時間から始める副業の第一歩を、3ステップで解説します。
```

## テンプレB：数字フック

```
[具体的な数字・結果]を達成するまでに、[期間・試行錯誤]がありました。
この記事では、その[方法/プロセス]をすべて公開します。
[読者が得られること]がわかる内容です。
```

## テンプレC：問いかけフック

```
[読者に問いかける疑問文]？
もし「はい」なら、この記事はあなたのためのものです。
[記事で答えること]を、具体例つきで説明します。
```

## テンプレD：衝撃・逆説フック

```
[常識]だと思っていた[テーマ]。
実は、[逆の事実・発見]でした。
この記事では、[なぜそうなのか]と[読者への示唆]を書きます。
```

## リード文の鉄則

| 行 | 役割 |
|----|------|
| 1行目 | フック（共感・数字・問い・衝撃のいずれか） |
| 2行目 | 信頼 or 深掘り（体験・根拠・共感の強化） |
| 3行目 | 約束（この記事で何がわかるか） |

## チェックリスト

- [ ] 3行以内で「自分ごと」になっている
- [ ] タイトルの約束と一致している
- [ ] 専門用語を使っていない（またはすぐ説明する）
- [ ] 次の段落（H2-1）に自然につながる
