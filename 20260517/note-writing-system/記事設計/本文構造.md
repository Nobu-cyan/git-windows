# 本文構造

`見出し構成.md` のH2/H3に沿って、以下の要素を各セクションに配置する。

## セクション別の役割

### 導入部（H2-1：問題提起）

- 読者の現状を言語化する
- 「あるある」で共感を作る
- この記事で解決する問題を1文で明示

**必須要素**：共感1文 + 問題の具体化

### 本論部（H2-2〜4：解決策・具体）

各H2に以下を含める：

| 要素 | 内容 |
|------|------|
| 主張 | そのセクションの結論を1文 |
| 理由 | なぜそうなのか |
| 具体例 | 体験談・ケース・Before/After |
| 数字 | 期間・金額・回数・割合など |
| 実践手順 | 読者が真似できるステップ |

### 結論部（H2-5：まとめ）

- 要点を3行以内で要約
- 次のアクションを1つに絞る
- `締めの一文.md` のCTAを挿入

## 段落の書き方

```
1段落 = 2〜4文
1文 = 40〜60字目安（スマホで読みやすい長さ）
```

- 改行を多めに（スマホ読者向け）
- 箇条書き・表で情報を整理
- 太字は1段落に1箇所まで（乱用しない）

## 説得力を上げる3要素（各H2に最低1つ）

1. **具体例**：「例えば、〇〇したとき…」
2. **数字**：「3ヶ月で」「月5回」「80%の人が」
3. **体験談**：「僕の場合は…」「クライアントさんでは…」

## 本文構成テンプレ（コピー用）

```markdown
## [H2タイトル]

[主張を1文]

[理由・背景を2〜3文]

### [H3-1]

[具体例 or 体験談]

[数字・データ]

### [H3-2]

[実践手順 or チェックリスト]

> 補足や注意点（引用ブロックで目立たせる）
```

## 文字数配分の目安（4,000字の場合）

| セクション | 文字数 |
|------------|--------|
| リード文 | 150〜250字 |
| H2-1 | 600〜800字 |
| H2-2 | 800〜1,000字 |
| H2-3 | 800〜1,000字 |
| H2-4 | 600〜800字 |
| H2-5 | 400〜600字 |
