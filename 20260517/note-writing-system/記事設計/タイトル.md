# バズるタイトルの型集

執筆時は必ず3案提示し、読者リサーチ・ニーズ把握の内容に照らして最適案を選ぶ。

## 型1：数字 + ベネフィット

```
[数字]で[理想の結果]を達成する[方法/ステップ]
```

**例**
- 週5時間で副業月3万円を達成した3ステップ
- 初心者が90日でnoteフォロワー500人を増やした方法

## 型2：共感 + 解決

```
[悩み]な人へ。[意外な事実/解決策]
```

**例**
- 何から始めればいいかわからない人へ。最初にやるべきは1つだけ
- 時間がないと言う人へ。1日15分で変わる習慣の作り方

## 型3：好奇心ギャップ

```
[常識]だと思っていた[テーマ]。実は[逆の真実]
```

**例**
- 毎日投稿が正解だと思っていたnote運用。実は週2本が最適だった
- タイトルに数字を入れるべきだと思っていた。実は〇〇の方が効く

## 型4：Before → After

```
[過去の自分]から[現在の自分]になった[期間/きっかけ]
```

**例**
- 副業0円から月5万円になった6ヶ月の全記録
- noteスキ0の記事が100スキを超えたまでの7日間

## 型5：リスト・チェック

```
[場面]で確認すべき[数字]つの[項目]
```

**例**
- note投稿前に確認すべき12項目
- 副業を始める前に知っておくべき5つの現実

## 型6：ターゲット明示

```
[属性]向け：[具体的なベネフィット]
```

**例**
- 会社員向け：本業を崩さず副業を始めるロードマップ
- note初心者向け：最初の1本で読まれる記事の書き方

## タイトル品質チェック

- [ ] 32文字前後（スマホで切れない長さ）
- [ ] ベネフィットが1文で伝わる
- [ ] ターゲットが想像できる
- [ ] クリックしたくなるが釣りではない
- [ ] 本文の内容と一致している

## 避けるタイトル

- 抽象的すぎる（「成功の秘訣」「大事なこと」）
- 煽りだけで中身と乖離（「絶対バズる」「誰でも月100万」）
- 専門用語だけで初心者が離れる
