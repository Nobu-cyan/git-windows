# 見出し構成（H2/H3の黄金比）

## 基本ルール

| 要素 | 推奨 |
|------|------|
| H2（大見出し） | 3〜5個 |
| H3（小見出し） | 各H2に2〜3個 |
| 1セクションの文字数 | 400〜800字 |
| 全体の文字数 | 3,000〜5,000字 |

## 黄金比テンプレート（5 H2構成）

```
## H2-1：問題提起・共感（読者の現状）
### H3：よくある悩み
### H3：なぜ解決できないのか

## H2-2：解決策の全体像
### H3：結論（先出し）
### H3：3ステップの概要

## H2-3：具体的方法①
### H3：やり方
### H3：具体例・数字

## H2-4：具体的方法② or 体験談
### H3：実践した結果
### H3：つまずきポイントと対処

## H2-5：まとめ・次のアクション
### H3：要点3行まとめ
### H3：今日からできる1ステップ
```

## 3 H2構成（短め・3,000字向け）

```
## H2-1：共感 + 問題
## H2-2：解決策 + 具体例
## H2-3：まとめ + CTA
```

## 見出しの書き方ルール

1. **H2は結論型**：「方法」ではなく「〇〇する3つの方法」
2. **H3はスキャン可能**：スマホで流し読みしても意味がわかる
3. **階層を飛ばさない**：H2の直下に本文を書き、H4は使わない
4. **数字を入れる**：「ステップ1」「3つのポイント」など

## 構成チェックリスト

- [ ] H2だけ読んでも記事の流れがわかる
- [ ] 各H2が1つのメッセージに絞られている
- [ ] 導入→本論→結論の順になっている
- [ ] 最後のH2にCTAがある
