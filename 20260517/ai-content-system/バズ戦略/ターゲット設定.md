# AI発信ターゲット設定

## メインペルソナ：「AIに乗り遅れたくない会社員」

| 項目 | 内容 |
|------|------|
| 年齢層 | 28〜42歳 |
| 職業 | 会社員（営業・マーケ・企画・管理職） |
| AIリテラシー | 初心者〜中級者（ChatGPTは知っているが使いこなせていない） |
| 読む時機 | 通勤中・昼休み・就寝前にスマホで |
| SNS習慣 | X（Twitter）でAI情報を拾っている |

### このペルソナの本音

**表面的な悩み**
- 「AIって結局どれを使えばいいの？」
- 「ChatGPTを試したけど、使い方がよくわからなかった」
- 「AIで仕事が楽になると聞くが実感がない」

**本質的な欲求**
- 「仕事で成果を出してチームに認められたい」
- 「AI波に乗り遅れて取り残される不安を消したい」
- 「すぐに職場で使えるネタが欲しい」

### 読者の言葉（コメント欄・Xで実際に見る表現）

- 「ChatGPTって具体的に何に使えるの？」
- 「AIツール多すぎてどれがいいかわからん」
- 「使ってみたけど結局Googleで調べた方が早かった」
- 「これ職場でも使えそう」

## サブペルソナ：「AI副業・発信に興味あるフリーランス」

| 項目 | 内容 |
|------|------|
| 年齢層 | 25〜38歳 |
| 職業 | フリーランス・副業挑戦中の会社員 |
| AIリテラシー | 中級者（毎日AIを使っている） |
| 読む動機 | 最新情報キャッチアップ、自分の発信ネタ探し |

### このペルソナへのアプローチ

- 最新モデル比較・ベンチマーク記事
- AIを使ったコンテンツ制作フロー公開
- 「AIで月〇万収益」系の体験談
