# AI発信バズるタイトル型集

執筆時は必ず3案提示し、ターゲット設定に照らして最適案を選ぶ。

---

## 型1：速報 × 体験談（最強パターン）

```
[AIモデル名]が[アップデート内容]。[時間]使ってわかったこと
```

**例**
- Claude Opus 4.7が正式リリース。48時間使ってわかった「本当の実力」
- GPT-5.5が6週間で登場。GPT-5.4から何が変わったか試した
- Gemini 3.1 Proが1Mトークン対応。100ページのPDFを読ませた結果

---

## 型2：比較 × 数字（クリック率が高い）

```
[AIツールA] vs [AIツールB]、[数字]タスクで比較した結果
```

**例**
- ChatGPT vs Claude、10タスクで比較した正直な結果
- GPT-5.5 vs Gemini 3.1 Pro、どっちが日本語が上手いか検証した
- 有料AI vs 無料AI、7つの仕事で比べて感じた「本当の差」

---

## 型3：初心者向け解説（安定してスキが集まる）

```
[AIの概念]って何？[ターゲット]が知っておくべき[数字]つのこと
```

**例**
- AIエージェントって何？会社員が知っておくべき3つのこと
- ChatGPTのハルシネーションとは？嘘をつくAIとの正しい付き合い方
- トークンって何？AI料金の仕組みを5分で理解する

---

## 型4：仕事活用型（会社員に刺さる）

```
[職種・場面]でAIを使ったら[結果]だった[方法/手順]
```

**例**
- 営業資料作りにClaudeを使ったら作業時間が半分になった話
- 会議の議事録、AIに任せたら1分で終わった。プロンプトを公開します
- Geminiに決算書を読ませたら30分かかる分析が5分で終わった

---

## 型5：トレンド解説（業界動向の読者が集まる）

```
[業界の変化]が起きている。[その意味]を解説する
```

**例**
- AnthropicがSpaceXと組んだ。AI計算コスト戦争の本当の意味
- Googleが毎月新AIを出す理由。2026年のAI競争は「速さ」で決まる
- AIに引用されるnote記事とは？2026年のコンテンツ戦略が変わった

---

## 型6：コスパ・無料活用（バズりやすいが差別化が必要）

```
無料で[期待以上のこと]ができる[ツール名]の使い方
```

**例**
- 無料でここまでできる。2026年5月版AI無料プラン徹底比較
- DeepSeek V4 Proを使ったらClaude並みだった。月0円で試す方法

---

## タイトル品質チェック

- [ ] 30〜35文字前後（スマホで切れない長さ）
- [ ] 「AIモデル名 + 数字 + ベネフィット」の3要素が揃っているか
- [ ] クリックしたくなるが釣りではないか
- [ ] 本文の内容と一致しているか
- [ ] 速報型は「日付・タイミング」のニュアンスが入っているか

## 避けるタイトル

- 「AIすごすぎた」（何がすごいか不明）
- 「ChatGPTの使い方」（検索流入は取れても差別化ゼロ）
- 「AIで人生変わった」（煽りが強く信頼を損なう）
- 専門用語だけのタイトル（「LLMのパラメータ効率化手法を比較」→ 初心者が離れる）
