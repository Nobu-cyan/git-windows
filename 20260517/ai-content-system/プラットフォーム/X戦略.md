# X（Twitter）× AI発信 戦略

## Xの役割

noteの「初速」を作るためのシェアプラットフォーム。
XでのRTが多いほどnoteのアルゴリズムにも有利に働く。

## AI系アカウントのポジション

### 2026年5月 Xで伸びるAI発信の型

| 型 | 例 | 伸び方 |
|----|----|----|
| 速報 + 一言コメント | 「Claude Opus 4.7が出た。コーディングベンチマーク64.3%は正直すごい」 | RT型 |
| 比較結果のスクショ | 「GPT-5.5 vs Claude、同じプロンプトで試した」 + 画像 | エンゲージ型 |
| 問いかけ | 「GPTとClaude、みなさんどっち使ってます？」 | リプ型 |
| 1分でわかる解説スレッド | 「AIエージェントを3ツイートで説明する[1/3]〜」 | フォロワー獲得型 |

---

## noteとXの連携

### 投稿テンプレ（note公開と同時にXへ）

```
📝 新記事を公開しました

[タイトルをそのまま]

[記事の一番「へー！」と思う部分を1〜2行で]

↓ 詳しくはnoteで
[noteのURL]

#ChatGPT #Claude #AI活用
```

### 速報時の連携フロー

```
AIニュース発生
  ↓（5分以内）
Xに「速報コメント」を投稿（noteリンクなし）
  ↓（〜48時間以内）
noteに速報記事を公開
  ↓（即座に）
XにnoteのURLを貼ったツイート投稿
  ↓
速報コメントのリプ欄にnote記事のURLを追加
```

---

## 避けること

- AIニュースの転記だけ（「〇〇が発表された」だけでは価値がない）
- 宣伝臭が強い投稿（「記事を読んでください！」だけ）
- 毎回noteリンクを貼る（フォロワーが離れる）

## Xでバズったらやること

1. RTしてくれたアカウントに「いいね」を返す
2. バズったポイントを次のnote記事に活かす
3. フォロワーが増えたタイミングでプロフィール記事を固定
