# テンプレ：解説型（AIツール・概念の入門記事）

**使いどき**：AIの概念・ツールの使い方を初心者向けに解説する  
**目標文字数**：2,500〜3,500字  
**ゴール**：「わかった！明日から使える」と読者に思わせる。AI検索にも引用されやすい

---

## タイトル（型3から選ぶ）

```
[AIの概念/ツール]って何？[ターゲット]が知っておくべき[数字]つのこと
```

---

## リード文

```markdown
「[AIのキーワード]」という言葉、最近よく聞くけれど、正直よくわからない——
そんな人は多いと思う。私もそうだった。
でも、[きっかけ]で調べてみたら、[シンプルな一言で何かがわかった]。
この記事では、[ターゲット]でも5分で理解できるように、わかりやすく解説する。
```

---

## 本文構造

### H2①：[テーマ]をひとことで言うと（300字）

- 専門用語を使わず、日常の言葉でたとえる
- 「〇〇でいうと△△のようなもの」「身近な例で言えば〜」
- 1つの定義を2〜3文で完結させる

### H2②：なぜ今[テーマ]が注目されているのか（400字）

- 最近のニュース・データを1つ引用
- 「仕事・生活にどう影響するか」を1〜2行で
- 難しくなったらここで読者は離れる → 絶対にわかりやすく

### H2③：[テーマ]の具体的な使い方（500字）

- ステップ形式（Step1 → Step2 → Step3）
- 実際のプロンプト・操作例を入れると信頼度UP
- スクリーンショット代わりに「入力例」と「出力例」を書く

```
入力例：「〇〇をしてください」

出力例：
[実際にAIが返した内容を要約・引用]
```

### H2④：よくある疑問 Q&A（300字）

- Q1：「[よくある誤解]」は本当？
- Q2：「[初心者がつまずくポイント]」はどうすれば？
- Q3：「無料でできる？」

### H2⑤：まとめ・明日から試せること（200字）

- 解説内容を3行で箇条書き
- 「まず試してほしい1つのアクション」を具体的に
- 次に読むべき記事へのリンク

## 解説型チェックリスト

- [ ] 中学生でも理解できる言葉に言い換えているか
- [ ] 専門用語を使った場合、直後に説明しているか
- [ ] 具体的な「入力例・出力例」が1つ以上あるか
- [ ] 「明日からできる1アクション」が書かれているか
- [ ] AI検索で引用されやすいよう「定義文」が本文中にあるか
