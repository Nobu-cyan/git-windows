# テンプレ：比較型（AIツール対決）

**使いどき**：複数のAIツールを同条件で比べた記事  
**目標文字数**：2,500〜3,500字  
**ゴール**：「どれを使えばいいか」の答えを出す。意思決定を助けることでスキ集まる

---

## タイトル（型2から選ぶ）

```
[AIツールA] vs [AIツールB]、[数字]タスクで比較した結果
```

---

## リード文

```markdown
「[AIツールA]と[AIツールB]、どっちを使えばいいですか？」
この質問をよく受ける。正直、「場合による」と言いたいが、
それでは答えにならない。だから[数字]タスクで実際に比べてみた。
結論から言うと、[ズバリ1行で結論]。
```

---

## 本文構造

### H2①：比較の前提・条件（200字）

- 使ったバージョン・モデル名を明記
- 比較した日時を書く（情報の鮮度を示す）
- プラン（無料/有料）を明記

### H2②：比較した[N]タスク一覧（200字）

- 箇条書きでタスク名を列挙
- タスク選定の理由を1行で

### H2③〜：各タスクの結果（各300字）

各タスクについて：
```
**タスク[番号]：[タスク名]**

[AIツールA]の回答：[要約または引用]
[AIツールB]の回答：[要約または引用]

→ 勝者：[AIツール名]
理由：[1〜2行]
```

### H2：総合結果（表）

```markdown
| タスク | [AIツールA] | [AIツールB] |
|--------|------------|------------|
| タスク1 | ○ | △ |
| タスク2 | △ | ○ |
...
| 総合 | X勝 | Y勝 |
```

### H2：こんな人は[A]、こんな人は[B]（300字）

- ユースケース別の推奨を明確に
- 「どちらでもいい」は書かない。必ず結論を出す

### H2：まとめ

- 結論の再掲（リード文と同じでOK）
- 「明日試してほしい1アクション」
- 次の比較記事へのリンク

---

## 比較チェックリスト

- [ ] 同条件（同じプロンプト）で比較しているか
- [ ] バージョン・日時が明記されているか
- [ ] 「どちらが優れているか」の結論が出ているか（曖昧にしない）
- [ ] 表で視覚的にまとめているか
