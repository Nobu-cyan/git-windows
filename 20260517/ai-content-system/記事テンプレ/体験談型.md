# テンプレ：体験談型（実際に使ってみた）

**使いどき**：自分がAIを試した体験・結果をリアルに伝える記事  
**目標文字数**：2,000〜3,000字  
**ゴール**：「自分も試してみたい」「この人の情報は信頼できる」という感情を引き出す

---

## タイトル（型4から選ぶ）

```
[AIツール]に[何をさせたか]を試したら[予想外の結果]だった
```

---

## リード文

```markdown
正直、[最初の期待・懐疑心を1文で]。
でも、試してみたら[結果を1文で]。
この記事では[何を試したか]と[得られた結果]をそのまま書く。
プロンプトも全部公開するので、ぜひ真似してみてほしい。
```

---

## 本文構造

### H2①：やってみようと思ったきっかけ（200字）

- 「なぜこれを試したのか」のエピソード
- 読者が「自分も同じ状況だな」と感じる状況設定
- 試す前の期待値・不安を正直に書く

### H2②：試した内容と条件（300字）

- 使ったAIツール・モデル名・バージョン
- 試した日時（情報の鮮度を示す）
- 使ったプロンプト（そのまま公開する）

```
使ったプロンプト：
「[実際のプロンプトをそのまま貼る]」
```

### H2③：結果（600字）

- Before（試す前の状態）→ After（試した後の状態）
- 良かった点 × 3、惜しかった点 × 1〜2（正直さが信頼を生む）
- 数字で示せる場合は必ず入れる（時間・文字数・精度など）

```
良かった点：
・[具体的に]
・[具体的に]
・[具体的に]

惜しかった点：
・[正直に]
```

### H2④：他のAIと比べてどうだったか（300字）

- 「同じことを[別のAI]でも試した」という比較を入れると価値UP
- 「[AIツールA]の方が良かったのは〇〇、[AIツールB]が上だったのは△△」

### H2⑤：まとめ・こんな人にはおすすめ（200字）

- 「どんな人に向いているか」を1〜2行で
- 「試してほしい1アクション」
- 次の体験談記事または比較記事へのリンク

---

## 体験談チェックリスト

- [ ] プロンプトを公開しているか（「真似できる」が価値）
- [ ] 良い点だけでなく惜しかった点も書いているか（正直さ＝信頼）
- [ ] 数字で示せる成果が1つ以上あるか
- [ ] 「自分もやってみたい」と思わせる書き方か
- [ ] 使ったモデルのバージョン・日時が明記されているか
