# テンプレ：速報型（AIニュース即日公開）

**使いどき**：新モデル発表・大型アップデートから48時間以内  
**目標文字数**：1,500〜2,000字  
**ゴール**：「このニュースの意味」を初心者に届け、スキ・シェアを得る

---

## タイトル（型1から選ぶ）

```
[モデル名]が[何をした]。[時間]使ってわかったこと
```

---

## リード文（3行以内）

```markdown
[日付]、[会社名]が[何を]発表した。
正直、最初は「また新しいやつか」と思ったけれど、
[具体的な驚き・使ってみた一言]。この記事では[読んで得られること]を書く。
```

---

## 本文構造

### H2①：[ニュース名]とは何か（300字）

- 発表内容を1〜2行でシンプルに説明
- 前のバージョン・競合との違いを数字で示す
- **ポイント**：AIが要約できない「自分の言葉での解釈」を1文加える

```
例：
○○が発表されたが、私が注目したのは〇〇ではなく△△だった。
なぜなら〜
```

### H2②：実際に[X]分使ってみた（500字）

- 試したタスクを3つ箇条書き
- 各タスクの結果を「Before → After」で書く
- 「思っていたより[良かった/悪かった]」の正直な感想を入れる

```
タスク1：〇〇を試した → [結果]
タスク2：△△を試した → [結果]
タスク3：□□を試した → [結果]
```

### H2③：前バージョン・競合と比べてどうか（400字）

- 具体的なベンチマーク数字を使う（参照元リンク必須）
- 「どの人に向いているか」を1〜2行で結論
- 表形式で比較すると読みやすい

### H2④：まとめ・次にやること（200字）

- 記事の結論を1文で
- 「明日試してほしい1つのアクション」
- 関連記事または次回予告

---

## 末尾テンプレ

```markdown
---
**参考情報**
- [公式発表リンク]
- [ベンチマーク参照元]

**次に読むなら**
- [関連記事タイトル]（リンク）
```

---

## 速報チェックリスト

- [ ] 発表から48時間以内か
- [ ] 「自分が試した」要素が1つ以上あるか
- [ ] 数字（スコア・時間・比率）が1つ以上あるか
- [ ] X（Twitter）で即シェアする文言を準備したか
