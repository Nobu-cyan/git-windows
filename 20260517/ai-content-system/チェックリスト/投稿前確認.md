# 投稿前 最終確認チェックリスト

バズ確認.md とあわせて使う。こちらは品質・ファクト確認に特化。

---

## 情報の正確性

- [ ] AIモデルのバージョン名が正確か（例：Claude Opus 4.7、GPT-5.5）
- [ ] ベンチマーク数値の参照元リンクを貼ったか
- [ ] 「〇〇%」「〇〇倍」などの数字に根拠があるか
- [ ] 古い情報（6ヶ月以上前）を最新のように書いていないか

## 読みやすさ

- [ ] 1文が60字以内か（長すぎると読みにくい）
- [ ] 1段落が3〜4行以内か
- [ ] 漢字・カタカナが連続しすぎていないか
- [ ] 見出しH2が3〜5個あるか
- [ ] 見出しH3が各H2に2〜3個あるか

## note投稿設定

- [ ] サムネイル画像を設定したか
- [ ] ハッシュタグを3〜5個設定したか（/プラットフォーム/ハッシュタグ集.md 参照）
- [ ] 有料設定の場合、無料公開部分が最初の500字以上あるか
- [ ] 目次（見出し）が表示設定になっているか

## 法的・倫理的確認

- [ ] 他サイトの文章をそのままコピーしていないか
- [ ] AIが書いた内容をそのまま投稿していないか（必ず自分の言葉で修正）
- [ ] 企業名・製品名の誤字がないか（OpenAI、Anthropic、Google DeepMind）

---

## 出力先

`/outputs/YYYYMMDD_タイトル.md` に保存してから投稿する。
