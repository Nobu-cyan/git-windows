# バズ確認チェックリスト（投稿前）

note投稿前に必ず全項目を確認する。
**7割以上チェックできなければ記事を出さない。**

---

## タイトルチェック

- [ ] 30〜35文字以内か（スマホで切れない長さ）
- [ ] AI × 数字 × ベネフィットの3要素が揃っているか
- [ ] クリックしたくなるが「釣り」ではないか
- [ ] 本文の内容と一致しているか
- [ ] ターゲット（AI初心者の会社員）が「自分のことだ」と思えるか

## リード文チェック

- [ ] 最初の3行で「自分の状況だ」と感じさせるか
- [ ] 「この記事を読むと何が得られるか」が明示されているか
- [ ] 長すぎない（3〜5行以内）

## 本文チェック

- [ ] 最新情報（2026年内）が含まれているか
- [ ] 数字が1つ以上あるか（スコア・時間・割合など）
- [ ] 「自分が試した体験談」または「自分の意見」が入っているか
- [ ] AIが代わりに書けない「一次情報・体験」があるか
- [ ] 専門用語を使った場合、直後に説明があるか
- [ ] 見出しだけ読んでも記事の概要がわかるか

## 締め・CTA チェック

- [ ] 「明日から試せる1アクション」が書かれているか
- [ ] 関連記事へのリンクがあるか
- [ ] スキ・コメントを促す一文があるか

## 速報型の場合（追加）

- [ ] 発表から48時間以内に公開できるか
- [ ] 公式発表元へのリンクがあるか
- [ ] Xシェア用の一文を準備したか

## 比較型の場合（追加）

- [ ] 同じ条件・同じプロンプトで比較しているか
- [ ] 「どっちがいい」の結論を出しているか（曖昧にしない）
- [ ] バージョン・日時を明記しているか

---

## 投稿後の初動アクション

公開から30分以内に以下を実行：

- [ ] XにnoteのURLをシェア（ハッシュタグ2〜3個付き）
- [ ] 過去の関連記事から新記事へ内部リンクを追加
- [ ] スキ数・閲覧数を1時間後に確認してXに報告投稿（あればRT狙い）
