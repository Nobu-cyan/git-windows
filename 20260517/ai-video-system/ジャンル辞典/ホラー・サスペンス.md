# ジャンル辞典：ホラー・サスペンス

## ジャンルの本質

**「恐怖は共有される——「見た？コレ怖すぎ」がシェアを生む」**

ホラー・サスペンスはTikTokで「怖いもの見たさ」の完視率が高く、
コメントが集まりやすいジャンル。和風ホラーは特に海外での反応が大きい。

## ホラー 5つの定番型

### 型1：振り返ると
**公式**：何かがいる気配 → 見てはいけないと思いながら振り返る → そこに何かが  
**なぜバズるか**：普遍的な恐怖体験。「自分だったら」という感情

### 型2：写真に写っていた
**公式**：何でもない日常写真 → ふと見返すと映っていた何か → 調べるほど怖くなる  
**なぜバズるか**：「日常の中の恐怖」が最も怖い

### 型3：だんだんわかってくる狂気
**公式**：普通に見えた人物 → 少しずつ異常に気づく → ラストで全貌が明らかに  
**なぜバズるか**：どんでん返し × 恐怖 = 最強の組み合わせ

### 型4：なぜか助かった理由
**公式**：危険な状況から奇跡的に助かる → 後から助かった理由がわかる → それが一番怖い  
**なぜバズるか**：「助かってよかった」→「え、そういうこと？」の反転

### 型5：禁じられた場所
**公式**：行ってはいけない場所 → 行ってしまう → 代償  
**なぜバズるか**：「なぜ行くんだ」という定番の緊張感と快感

## 演出の型（映像指示に使う）

| 演出 | 効果 | プロンプトキーワード |
|------|------|-------------------|
| 暗がりに浮かぶ顔 | 不気味・恐怖 | `pale face in darkness, horror, unsettling` |
| 廃屋・廃墟 | 禁忌の場所 | `abandoned house, dark corridor, flickering light` |
| 人形・鏡 | 和風ホラーの定番 | `japanese doll, cracked mirror, dim light` |
| 霧の森 | 迷い込む恐怖 | `misty forest, fog, isolated figure` |
| 影だけが動く | 本体は見せない恐怖 | `shadow moving independently, dark hallway` |
| 赤い着物の後ろ姿 | 和風の怖さ | `woman in red kimono, facing away, bamboo forest` |

## ホラー演出の鉄則

- **見せすぎない** ——想像させる方が実物より怖い
- **音が9割** ——BGMの間、効果音のタイミングが恐怖を作る
- **日常に混ぜる** ——非日常より「日常の中の非日常」が怖い
- **説明しない結末** ——「何があったのか」を視聴者に考えさせる
