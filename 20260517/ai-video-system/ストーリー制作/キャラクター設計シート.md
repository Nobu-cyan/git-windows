# キャラクター設計シート

新しい作品を作るときに必ず記入する。キャラが立つほど視聴者の感情移入が深まる。

---

## 基本設計

```
【キャラクター名】
【ジャンル】
【役割】：主人公 / 相手役 / 敵 / 脇役

━━ 外見 ━━
外見の特徴：
服装・装備：
AI映像向けビジュアル指示（一文で）：

━━ 内面 ━━
年齢・職業・立場：
一言で言うとどんな人？：
最大の強み：
最大の弱み（傷）：
隠している秘密：
口癖・特徴的な言動：

━━ 物語における役割 ━━
物語開始時の状態：
物語を通じて何が変わる？：
視聴者にどんな感情を抱かせたい？：
```

---

## キャラクターの「傷」が物語を動かす

バズるキャラクターには必ず「傷」がある。

| ジャンル | よくある「傷」の例 |
|---------|----------------|
| バトル・時代劇 | 守れなかった大切な人、負けた過去 |
| ラブストーリー | 過去の失恋、自己肯定感の低さ |
| ダークファンタジー | 呪われた血、力を使った代償 |
| SF | 人間として扱われなかった過去 |
| 青春 | 挫折、才能への疑い |
| ホラー | 封じ込めていた過去の記憶 |

## 主人公の感情変化グラフ

```
感情レベル
10│                              ★クライマックス
 │                         ／
 5│           ／＼          /
 │    ／＼  /   ＼        /
 0│──────────────────────→ 時間
    開始  第一の試練 どん底  決断  解放
```

視聴者は主人公と感情を共有している。
クライマックスまでの「谷」が深いほど、頂点での感動が大きくなる。

## キャラクター記入例（バトル系）

```
【キャラクター名】 黒鷹（くろたか）
【ジャンル】 時代劇バトル
【役割】 主人公

━━ 外見 ━━
外見：傷だらけの顔、右目に眼帯、白い着物に黒の羽織
服装・装備：刀一本（師匠から受け継いだ古刀）
AI映像向け：「scarred samurai, white kimono, black haori, eyepatch, lone warrior」

━━ 内面 ━━
年齢・立場：32歳、浪人
一言で言うと：強さを求めた末に孤独になった男
最大の強み：究極の集中力、一撃必殺の剣技
最大の弱み：守るべき人がいない、理由を失った戦い
隠している秘密：師匠を自分の手で斬った
口癖：（無口。言葉より行動で語る）

━━ 物語における役割 ━━
開始時の状態：目的なく生きる殺し屋
変化：子どもを守ることで「守る理由」を取り戻す
視聴者に抱かせたい感情：孤独感への共感→再生への涙
```
