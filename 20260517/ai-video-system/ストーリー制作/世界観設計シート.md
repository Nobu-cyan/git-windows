# 世界観設計シート

物語の舞台を設計する。世界観が明確なほどAI映像の品質が上がる。

---

## 基本設計

```
【作品タイトル（仮）】
【ジャンル】
【舞台となる時代・場所】

━━ 世界の基本ルール ━━
この世界の「普通」は何か？：
この世界で「禁忌」とされていることは？：
主人公を取り巻く社会的状況：
物語の中心となる「対立軸」：

━━ 視覚的な世界観 ━━
主なロケーション：
色彩・光の特徴（暖色/寒色、明るい/暗い）：
時間帯（昼/夜/夕暮れ）：
天気・季節：
AI映像生成向け世界観キーワード（英語）：

━━ 音楽・音響の世界観 ━━
BGMのジャンル・雰囲気：
重要なSE（効果音）：
無音を使う場面：
```

## ジャンル別 世界観テンプレ例

### バトル・アクション
```
時代：現代 or 架空
対立軸：強者vs弱者、組織vs個人
色彩：高コントラスト、強い影
カメラ：低アングル（主人公を大きく見せる）
必須ロケーション：廃工場、路地裏、山頂
```

### 時代劇
```
時代：江戸〜幕末 or 架空和風
対立軸：義vs欲、伝統vs変革
色彩：褪せた和色（藍・朱・萌黄）
カメラ：引きのロングで空間を見せる
必須ロケーション：宿場町、山道、城下町、竹林
```

### ダークファンタジー
```
時代：架空中世 or 滅びかけた未来
対立軸：善悪が逆転した世界
色彩：紫・黒・金（禁断の輝き）
カメラ：上からの俯瞰（神の視点）
必須ロケーション：廃城、地下神殿、呪われた森
```

### ラブストーリー
```
時代：現代（共感が最大化）
対立軸：二人の間にある距離・秘密
色彩：柔らかい暖色〜青への転換（幸福→別れ）
カメラ：クローズアップで感情を捉える
必須ロケーション：並木道、喫茶店、駅のホーム
```

### SF
```
時代：近未来〜遠未来
対立軸：技術vs人間性、管理vs自由
色彩：青・白・ネオン（光と影のコントラスト）
カメラ：ワイドで広大さ → クローズアップで孤独
必須ロケーション：廃墟、宇宙ステーション、地下都市
```

## 世界観の「ルール」が物語を強くする

「このルールが破られたとき」に物語が動く。

例：
- 「感情を持ってはいけない機械の世界」→ 機械が感情を持つ → 物語が始まる
- 「女は戦ってはいけない時代」→ 女侍が現れる → 対立が生まれる
- 「愛することを禁じられた魔族」→ 魔族が人間を愛する → 悲劇が動き出す
