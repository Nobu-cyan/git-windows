# ターゲット設定

## メインペルソナ：「AIに乗り遅れたくない会社員」

| 項目 | 内容 |
|------|------|
| 年齢層 | 28〜42歳 |
| 職業 | 会社員（営業・マーケ・企画・総務） |
| AIリテラシー | 初心者〜中級者（ChatGPTは知っているが使いこなせていない） |
| 視聴シーン | 通勤電車・昼休み・帰宅後にスマホで縦型動画を見る |
| SNS習慣 | TikTok / YouTubeショートを毎日チェック |

### このペルソナの本音

**表面的な悩み**
- 「AIって何ができるの？結局よくわからない」
- 「動画を作れるようになりたいが、ソフトが難しそう」
- 「AIで副業できると聞いたが、具体的な方法がわからない」

**本質的な欲求**
- 「職場でAIを使いこなして一目置かれたい」
- 「将来のために新しいスキルを身につけたい」
- 「時間を減らして自由な時間を増やしたい」

### このペルソナが「止まる」動画

- サムネイルに大きく「AIで〇〇が変わった」
- 最初の3秒で「これ自分のことだ」となる状況設定
- 「知らなかったら損する」という焦りを感じるフック

## サブペルソナ：「AI副業・動画クリエイター志望」

| 項目 | 内容 |
|------|------|
| 年齢層 | 22〜35歳 |
| 職業 | フリーランス・副業挑戦中 |
| AIリテラシー | 中級者（AIツールを日常的に使っている） |
| 視聴目的 | 最新ツール情報・収益化ヒントを探している |

### このペルソナへのアプローチ

- 最新ツール比較動画（Runway / HeyGen / Kling の性能差）
- 「AIで月〇万」系の体験談・収益化事例
- 制作フローの公開（プロンプト・設定値まで見せる）
