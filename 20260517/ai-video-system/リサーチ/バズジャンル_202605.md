## バズるストーリー動画の構造（2026年版）

### 10〜30秒 ショートバズの黄金公式

```
[0〜3秒] 衝撃の映像 or 謎かけナレーション
          → 「この先何が起きるのか」が読めない状態を作る

[3〜20秒] 急展開の本編
          → 予想を裏切る展開・感情の急激な振れ幅

[20〜30秒] どんでん返し or 感情の頂点
           → 「嘘でしょ」「もう一度見たい」という余韻
```

### 3分 ミドル動画の感情設計

```
[0〜15秒]   世界観の提示 + キャラクターへの感情移入
[15〜90秒]  葛藤・困難・逆境
[90〜150秒] 決断の瞬間
[150〜180秒] 解放・勝利・感動の頂点 + 次回予告
```
