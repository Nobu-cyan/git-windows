# 脚本チェックリスト

投稿前に必ず確認する。**6割以下なら書き直す。**

---

## ストーリーの質

- [ ] 最初の3秒に「止まる理由」があるか（衝撃/謎/感情）
- [ ] キャラクターに「傷」があり、感情移入できるか
- [ ] 予想を裏切る展開が1回以上あるか
- [ ] 感情の最高点（クライマックス）が明確か
- [ ] 「もう一度見たい」または「続きが見たい」で終わっているか
- [ ] 答えを全部出しすぎていないか（余白を残す）

## AI映像化の実現性

- [ ] 映像指示が具体的で、Runway/Klingが生成できそうか
- [ ] 1シーンが長すぎないか（AI生成は5〜10秒単位が基本）
- [ ] 無理な人数・複雑な動き・文字の読み取りを要求していないか
- [ ] BGM・SE の指示が具体的か（Sunoで生成できる内容か）

## ジャンルとしての正しさ

- [ ] ジャンル辞典のバズパターンを活用しているか
- [ ] ジャンルに合った色彩・カメラ・演出メモがあるか
- [ ] タイトルがジャンル辞典の「バズるタイトル例」の型に沿っているか

## 実用情報

- [ ] 尺が収まっているか（ショート：60秒以内 / ミドル：5分以内）
- [ ] サムネイル案が記載されているか
- [ ] ハッシュタグが3〜5個（YouTube）または2〜3個（TikTok）あるか
- [ ] outputs/scripts/ に正しいファイル名で保存したか
  - 形式：`YYYYMMDD_ジャンル_タイトル.md`
