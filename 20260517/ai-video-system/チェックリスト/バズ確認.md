# バズ確認チェックリスト（動画投稿前）

**7割以上チェックできなければ投稿しない。**

---

## フック（0〜3秒）

- [ ] 最初の映像に動き or 大きいテキストがあるか
- [ ] ナレーションは0秒から始まっているか（無音の出だしはNG）
- [ ] 「衝撃 / 疑問 / 数字 / Before-After」のいずれかから始まっているか
- [ ] サムネイルを見ただけで内容が10字で伝わるか

## 本編

- [ ] 専門用語を使った場合、直後に説明があるか
- [ ] 数字（スコア・時間・金額・割合）が1つ以上あるか
- [ ] 「自分が試した」一次情報が含まれているか（AI転記だけはNG）
- [ ] 視聴維持率を下げる「だれる部分」がないか（尺が適切か）
- [ ] 字幕は1画面20字以内か

## CTA（最後の5〜10秒）

- [ ] フォロー・いいね・コメントのどれか1つだけに絞っているか
- [ ] 「次の動画へ」の動線があるか（関連動画・カード）

## プラットフォーム設定

- [ ] YouTube：タイトルに主要キーワードが入っているか
- [ ] YouTube：説明文に100字以上のテキストがあるか
- [ ] TikTok：AI生成コンテンツラベルをつけたか
- [ ] ハッシュタグ：YouTube 3〜5個 / TikTok 2〜3個に絞っているか

## 投稿後30分のアクション

- [ ] XにYouTubeリンクを投稿したか
- [ ] 過去動画の説明欄から新動画にリンクを貼ったか
- [ ] 最初のコメントを自分で書いたか（「質問あればどうぞ」）
